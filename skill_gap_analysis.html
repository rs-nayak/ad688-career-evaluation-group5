Skill Gap Analysis

Team Skills vs. Market Demand (Data Scientist Postings, NAICS 5417)

This page compares our team’s self-rated skills with the skills most often requested in the 760 Data Scientist postings from the Market Baseline (January to August 2026).

Market demand from job postings

import pandas as pd
import plotly.express as px
from IPython.display import Markdown, display
import theme  # applies the "course" Plotly template

jobs = pd.read_csv("output/career_market_panel.csv")

skill_cols = ["skills_array", "specialized_skills_array",
              "common_skills_array", "software_skills_array"]
text = jobs[skill_cols].fillna("").astype(str).agg(" ".join, axis=1)

# display name -> search pattern in the skills text
patterns = {
    "Python": r"Python",
    "SQL": r"\bSQL\b",
    "Machine Learning": r"Machine Learning",
    "Deep Learning": r"Deep Learning",
    "TensorFlow": r"TensorFlow",
    "Data Pipelines": r"Data Pipeline|\bETL\b|Extract Transform Load",
    "Cloud (AWS/Azure/GCP)": r"Amazon Web Services|\bAWS\b|Azure|Google Cloud|\bGCP\b",
    "Statistics": r"Statistic",
    "Tableau": r"Tableau",
    "Power BI": r"Power BI",
    "Databricks": r"Databricks",
    "Kubernetes": r"Kubernetes",
}

demand = pd.Series({
    name: text.str.contains(pat, case=False, regex=True).mean()
    for name, pat in patterns.items()
}).sort_values(ascending=False)

demand_pct = (demand * 100).round(1)
print(f"Share of all {len(jobs)} postings that list each skill")
demand_pct.rename("% of postings listing skill").to_frame()

Skill gaps

Required level is scaled from market demand: the most-demanded skill maps to 5, and others scale proportionally. A gap is the required level minus a member’s level (0 if they meet it). This is a relative measure, not an absolute standard of expertise.

required = (demand / demand.max() * 5)
gap = (required - df_skills[required.index]).clip(lower=0).round(1)

fig = px.imshow(gap, text_auto=".1f", color_continuous_scale="Reds",
                aspect="auto",
                title="Skill Gaps vs. Market Demand (higher = bigger gap)")
fig.show()
summary = pd.DataFrame({
    "Team average": df_skills.mean().round(1),
    "Market-required level": required.round(1),
    "Average gap": gap.mean().round(1),
}).sort_values("Average gap", ascending=False)

Improvement plan

Priorities per member

Each member’s three largest gaps, taken from the gap heatmap above.

top3 = {
    name: [s for s in row.sort_values(ascending=False).head(3).index if row[s] > 0]
    for name, row in gap.iterrows()
}
lines = []
for name, skills in top3.items():
    if skills:
        items = ", ".join(f"**{s}** (gap {gap.loc[name, s]})" for s in skills)
    else:
        items = "no gaps against the market-required levels"
    lines.append(f"- **{name}:** {items}")
display(Markdown("\n".join(lines)))

Team collaboration

The strongest member on each priority skill teaches the others who need it.

lines = []
for s in priority_skills:
    teacher = df_skills[s].idxmax()
    learners = [n for n, sk in top3.items() if s in sk and n != teacher]
    if learners:
        lines.append(f"- **{s}:** {teacher} (level {df_skills.loc[teacher, s]}) "
                     f"leads a short session for {', '.join(learners)}.")
display(Markdown("\n".join(lines)))
  • Machine Learning: Richa (level 3) leads a short session for James, Ben, Victoria.
  • Python: Richa (level 4) leads a short session for James, Ben, Victoria.
  • SQL: Richa (level 4) leads a short session for Victoria.
  • TensorFlow: Richa (level 2) leads a short session for James.

To make this work in practice, the team will hold one 30-minute skill-share each week, with the teacher walking through a small example. Members will also pair up on the project’s own tasks, such as cleaning data or building a chart, so that each person practices their priority skills on real work. Finally, we will build one shared practice project on this project’s market dataset and review each other’s changes through GitHub before merging.
